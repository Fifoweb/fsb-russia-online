# ФСБ | Россия Онлайн

Отдельный статический сайт игровой фракции, без регистрации, авторизации и серверных сервисов.

Сайт: https://fifoweb.github.io/fsb-russia-online/

Репозиторий: https://github.com/Fifoweb/fsb-russia-online

Разделы: главная, о службе, подразделения, звания, крафты, материалы сотрудника, галерея, вступление, FAQ, источники и уточнения. Разделы открываются по прямым hash-ссылкам. Главная не содержит полный справочник.

Калькулятор: 39 справочных рецептов из ГИБДД «Россия Онлайн», категории, поиск, сортировка, избранное, несколько предметов, количества 1–99 999, отдельные суммы каждого типа материалов, вес, удаление, очистка, буфер обмена, TXT и PNG. Расчёт и избранное сохраняются в localStorage, поддерживается обновление между вкладками. На телефоне — раскрываемая сводка с управлением с клавиатуры.

Доступность и рецепты ФСБ не подтверждены. Все импортированные позиции имеют `fsbVerified: false`, на сайте и в экспортах есть пометка. Неизвестный вес поддерживается как `null` с предупреждением о неполном итоге. Чужие требования к кандидатам и регламенты не выданы за действующие правила.

## Устройство

- `dist/index.html`, `styles.css`, `app.js` — структура, оформление, взаимодействия.
- `dist/catalog-data.js` — единственный редактируемый источник рецептов, `catalog.json` — соответствующий снимок.
- `dist/core.js` — проверка количества и точные расчёты в целых граммах.
- `dist/export-image.js` — Canvas PNG с переносом длинных названий.
- `dist/content-data.js`, `resources-data.js` — справочная информация, материалы, FAQ, галерея.
- `dist/assets/` — локальные WebP, изображения предметов, шрифт Manrope и его лицензия.
- `docs/SOURCES.md` — происхождение материалов и список уточнений; `docs/DOMAIN.md` — подключение домена.

## Проверка и запуск

`npm test` запускает проверки расчётов, сохранения, поиска, ссылок и ресурсов. Canvas-тесты используют `@napi-rs/canvas`, если модуль доступен. Браузерная проверка использует отдельно установленный Playwright (`npm install --prefix .qa-tools --ignore-scripts playwright`) и уже установленный Chrome, без установки нового браузера. Запуск: `npm run test:browser`; адрес можно задать через `FSB_QA_URL`.

Локальный запуск: `npm run dev`, затем http://127.0.0.1:4181/. Публикационный корень — `dist/`. Для локального просмотра также подойдёт любой статический HTTP-сервер. Открытие HTML через `file://` не подходит для ES-модулей.

## Публикация на GitHub Pages

Изменения ветки `main` автоматически проходят проверки и публикуются workflow `.github/workflows/deploy.yml`. В Settings → Pages выбран источник GitHub Actions. Публикуется только папка `dist/`; исходники, тесты и документация не входят в сайт. Сборка и установка зависимостей для сайта не требуются.

Проект и опубликованный сайт ГИБДД не изменяются. Серверные секреты и внешние API не нужны. Подключение домена выполняется после выбора адреса владельцем — см. `docs/DOMAIN.md`.
