# Размещение на собственном домене

Приложение полностью статическое, публикационный корень — `dist/`. Хостинг — GitHub Pages, отдельный репозиторий `Fifoweb/fsb-russia-online`, публикация через GitHub Actions из ветки `main`. Адрес проекта: https://fifoweb.github.io/fsb-russia-online/

Нужен HTTPS; серверные ключи, БД и авторизация не требуются. Пути ресурсов относительные, разделы используют hash-маршруты, поэтому специальный rewrite для страниц не нужен. Сайт работает как в подпапке GitHub Pages, так и в корне собственного домена.

Короткие варианты для выбора: `fsbro.ru`, `rofsb.ru`, `fsb-ro.ru`, `fsb-online.ru`. Доступность и стоимость не проверялись.

После выбора владельцем:

1. Проверить доступность и условия у регистратора и зарегистрировать выбранный адрес.
2. Подтвердить владение доменом в GitHub, затем добавить выбранный адрес в репозитории: Settings → Pages → Custom domain.
3. Настроить DNS по актуальной инструкции GitHub Pages для выбранного типа адреса. До выбора адреса DNS не менять. Инструкция: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
4. Дождаться подтверждения DNS и сертификата, включить Enforce HTTPS.
5. Обновить `canonical`, `og:url` и `og:image` в `dist/index.html`; адреса проверок в `scripts/browser-qa.mjs` и `scripts/sync-public-assets.mjs`; затем контрольные суммы в `scripts/assets-manifest.json`. При необходимости настроить основную версию с www или без www.
6. Повторно проверить публичное открытие, изображения, прямые ссылки, копирование и PNG.

Покупка домена и изменение DNS в этой работе не выполнялись.
